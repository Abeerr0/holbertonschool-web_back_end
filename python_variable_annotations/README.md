# Python - Variable Annotations

A Python project focused on type annotations, variable typing, duck typing, and static type checking with `mypy`.

## Requirements

* Python 3.9
* Ubuntu 20.04
* pycodestyle
* mypy

## Tasks

The project includes exercises covering:

* Function and variable annotations
* Lists, tuples, unions, sequences, and callables
* Duck typing
* Type checking with `mypy`
