# Python - Async Comprehension

A Python project focused on asynchronous generators, async comprehensions, and running coroutines concurrently with `asyncio`.

## Requirements

* Python 3.8
* Ubuntu 20.04
* pycodestyle 2.5.x

All functions and coroutines are documented and type-annotated.

## Tasks

The project covers:

* Asynchronous generators
* Async comprehensions
* Concurrent execution with `asyncio.gather()`
* Measuring asynchronous runtime

## Testing

Run the provided test files:

```bash
./N-main.py
```
