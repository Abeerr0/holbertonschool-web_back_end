# Python - Async

A Python project focused on asynchronous programming with `asyncio`, covering coroutines, concurrent execution, runtime measurement, and tasks.

## Requirements

- Python 3.8
- Ubuntu 20.04
- pycodestyle 2.5.x

All functions and coroutines are documented and type-annotated.

## Tasks

The project covers:

- Async coroutines
- Concurrent execution with `asyncio.gather()`
- Runtime measurement
- `asyncio.Task`
- Randomized delays

## Testing

Run the provided test files:

```bash
./N-main.py
```
