# NoSQL

## Description

This project covers NoSQL concepts and MongoDB usage: what NoSQL means, the difference between SQL and NoSQL, ACID properties, document storage, NoSQL types, benefits of NoSQL databases, and how to query, insert, update, and delete information in a NoSQL database using MongoDB and PyMongo.

## Requirements

- All Mongo shell files are interpreted on Ubuntu 20.04 LTS using MongoDB (version 4.4).
- All Mongo shell files should end with a new line.
- The first line of all Mongo shell files should be a comment: `// my comment`.
- All Python scripts are interpreted/compiled on Ubuntu 20.04 LTS using python3 (version 3.9) and PyMongo (version 4.8.0).
- All Python files should end with a new line.
- The first line of all Python files should be exactly `#!/usr/bin/env python3`.
- Code should follow the pycodestyle style (version 2.5.\*).
- All modules and functions should have documentation.
- Code should not be executed when imported (`if __name__ == "__main__":`).
